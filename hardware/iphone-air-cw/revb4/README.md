# Rev B4 iPhone Air USB-C CW prototype

This folder publishes the fabrication and assembly data for an individual student project: a USB-C-powered 2.4 GHz continuous-wave source for wearable Bluetooth backscatter experiments.

## Public technical information

The technical information in this release is intentionally available to the public. Anyone may download, copy, and further share the published technical information without access or confidentiality restrictions. This notice concerns dissemination of this technical information. It does not classify physical components or certify a supplier's sourcing transaction.

The package contains the matching released Rev B4 fabrication and normal assembly files. The ten manufacturing files are unchanged from the original Rev B4 prototype package. The quote scope requests five fabricated boards, with two fully assembled normal boards having U4 fitted and three bare boards, all depanelized.

This is a prototype submitted for manufacturing and quotation review. It has not been validated by fabricated-board measurements. A supplier must confirm manufacturability, component availability, and any proposed changes. Publication and quote review do not authorize purchases or production.
